This project reproduces the analytical pipeline described in the paper
Assessment of MicroRNAs Associated with Tumor Purity by Random Forest Regression
(https://pmc.ncbi.nlm.nih.gov/articles/PMC9138977/￼).

The original study investigated how microRNA expression profiles relate to tumor purity across cancer samples, using Random Forest Regression (RF) to identify microRNAs most strongly associated with tumor purity levels.

This reproduction implements the core workflow of the paper, including:
	•	Preprocessing and normalization of microRNA expression data
	•	Integration of tumor purity scores
	•	Training and evaluation of a Random Forest Regression model
	•	Identification of key microRNAs through feature importance analysis
	•	Visualization of regression performance and important features

All analyses follow the methodology outlined in the original publication, with code adapted for clarity, reproducibility, and ease of use.
